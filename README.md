# ZeroNote

Редактор для Windows, который совмещает две вещи, сегодня живущие раздельно:
скорость и универсальность Notepad++ — и работу с папками заметок как с
проектами, по модели VS Code.

Хранилище Obsidian открывается как обычная папка. ZeroNote не повторяет чужой
формат: у него свой файл проекта, а связи между заметками (`[[ссылки]]`,
frontmatter, теги) он понимает как свойство markdown, а не как «режим
совместимости». Подробнее — решение Р-022 в [DESIGN.md](DESIGN.md).

> **Состояние: этап 1 завершён, версия 0.1.0.**
> Редактором можно пользоваться. Дерева папок и проектов пока нет — они
> относятся к этапу 2.

Замысел, модель данных, инварианты и журнал решений — в [DESIGN.md](DESIGN.md).

## Что уже работает

- Окно с вкладками, перетаскивание вкладок и перетаскивание файлов в окно.
- Создание, открытие, сохранение, «сохранить как», закрытие с подтверждением.
- Кодировки: UTF-8, UTF-16 LE/BE, windows-1251, windows-1252, IBM866, KOI8-R.
  Определяются сами, видны в строке состояния, меняются вручную — отдельно
  «интерпретировать как» и отдельно «преобразовать в».
- Переносы строк CRLF/LF/CR: сохраняются как были; смешанный файл спрашивает,
  к чему привести, и только при первом сохранении.
- Восстановление сессии после перезапуска, включая несохранённые вкладки
  без файла на диске. Черновики пишутся через пару секунд после правки.
- Отслеживание внешних изменений: чистый буфер перечитывается сам, изменённый
  спрашивает, исчезнувший файл предлагает выбор.
- Поиск и замена, в том числе регулярными выражениями.
- Отмена/повтор, переход к строке, операции со строками.
- Горячие клавиши в раскладке Notepad++, переназначаются файлом.
- Светлая и тёмная темы, следование системной, свои темы файлом без перезапуска.
- Файлы свыше 50 МБ открываются в режиме только для чтения.

## Чего пока нет

Дерева папок и проектов, подсветки синтаксиса, поиска по папке, `[[ссылок]]`
между заметками — это этап 2. Автосохранения по таймеру в файл тоже нет:
несохранённое хранится в черновиках и переживает падение, но в сам файл
попадает только по Ctrl+S.

Только Windows 10/11, только локальная файловая система. Синхронизация, Linux,
плагины, LSP, сравнение файлов и прочее — вне области первого круга, см. раздел
«Отложено» в `DESIGN.md`.

## Сборка из исходников

Нужны: Rust (msvc), Node 20+, WebView2 (есть в Windows 11 из коробки).

```bash
npm install
```

Отладочный запуск:

```bash
npm run tauri dev
```

Релизная сборка и установщик:

```bash
npm run tauri build
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`.

## Для тестировщиков

Сборка 0.1.0: `ZeroNote_0.1.0_x64-setup.exe`, 2,23 МБ.
SHA-256 `868332049B5139173438BDF7772C0D0E31D1C248062AB2519A427EAB9F0E6C23`.

### Установщик не подписан

Сертификат подписи кода для проекта не покупается, поэтому при запуске
установщика Windows покажет синий экран **«Система Windows защитила ваш
компьютер»**. Это ожидаемо и означает ровно одно: издатель неизвестен Microsoft.

Чтобы продолжить: **«Подробнее»** → **«Выполнить в любом случае»**.

Перед этим имеет смысл сверить контрольную сумму файла с опубликованной вместе
со сборкой:

```powershell
Get-FileHash .\ZeroNote_0.1.0_x64-setup.exe -Algorithm SHA256
```

### Что нужно на машине

Windows 10 или 11 и компонент **WebView2**. В Windows 11 он есть из коробки;
на Windows 10 установщик подтянет его сам, для чего понадобится интернет.
Прав администратора не нужно: приложение ставится только для текущего
пользователя.

### Куда приложение кладёт данные

Приложение не засоряет систему: настройки, темы, сессия и черновики лежат рядом
с исполняемым файлом, в подпапке `data\`.

Установка идёт **только для текущего пользователя**, в `%LOCALAPPDATA%\ZeroNote\`,
и не требует прав администратора. Это не косметика: в `Program Files` папка была
бы недоступна на запись, и черновики несохранённых файлов молча терялись бы.

```
%LOCALAPPDATA%\ZeroNote\
  zeronote.exe
  uninstall.exe
  data\
    settings.toml      настройки, правятся руками
    keymap.toml        переназначение горячих клавиш
    themes\            ваши темы
    session.toml       какие вкладки были открыты
    drafts\            несохранённое
```

Если папка приложения окажется недоступной на запись — например, при запуске
с флешки с защитой от записи, — приложение перейдёт на
`%LOCALAPPDATA%\ZeroNote-data\` и скажет об этом в строке состояния.

**Деинсталлятор пользовательские данные не трогает** — проверено: после удаления
папка `data\` со всем содержимым остаётся на месте. Чтобы убрать и её, удалите
`%LOCALAPPDATA%\ZeroNote\` вручную.

### На что смотреть в первую очередь

Проект держится на инвариантах — правилах, которые не должны нарушаться никогда.
Если заметите нарушение любого из них, это важнее любой другой находки:

1. **Файл изменился сам.** Открыли, ничего не правили, сохранили — и файл стал
   другим: сменилась кодировка, переносы строк, появилась или пропала пустая
   строка в конце.
2. **Что-то записалось в `.obsidian`.** Туда не должно попадать ничего.
3. **Файл побился при сохранении.** Особенно если приложение или система
   упали в этот момент.
4. **Пропало несохранённое.** Убейте процесс через диспетчер задач с грязными
   вкладками и запустите снова — всё должно вернуться.
5. **Кодировка определилась неверно** — крякозябры вместо текста.

### Как сообщать о проблемах

К отчёту полезно приложить: версию Windows, версию ZeroNote, что делали, что
ожидали, что получили. Для проблем с открытием файла — его кодировку и тип
переносов строк из строки состояния, а лучше сам файл: угадать кодировку
по описанию невозможно.

Если приложение ведёт себя странно после обновления, посмотрите на полосу
предупреждений вверху окна — туда попадают ошибки в `settings.toml`,
`keymap.toml` и файлах тем.
