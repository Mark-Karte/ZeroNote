# ZeroNote

Редактор для Windows, который совмещает две вещи, сегодня живущие раздельно:
скорость и универсальность Notepad++ — и работу с хранилищами Obsidian как с
проектами, по модели VS Code.

> **Состояние: ранняя разработка, этап 1 из плана.**
> Сейчас в репозитории каркас приложения и измерительный стенд. Редактора ещё
> нет — он появляется в задаче 4 этапа 1. Ставить как рабочий инструмент рано.

Замысел, модель данных, инварианты и план — в [DESIGN.md](DESIGN.md).

## Что будет в первом круге

- Окно с вкладками, перетаскивание вкладок и файлов.
- Создание, открытие, сохранение, «сохранить как», закрытие с подтверждением.
- Определение и ручная смена кодировки, отображение кодировки и типа переносов.
- Восстановление сессии, включая несохранённые буферы без файла на диске.
- Отслеживание внешних изменений файла.
- Отмена/повтор, переход к строке, базовые операции с текстом.
- Горячие клавиши в раскладке Notepad++.
- Светлая и тёмная темы, следование системной, темы файлом без перезапуска.

Только Windows 10/11, только локальная файловая система. Синхронизация, Linux,
плагины, LSP, сравнение файлов и прочее — вне области первого круга, см. раздел
«Отложено» в `DESIGN.md`.

## Сборка из исходников

Нужны: Rust (msvc), Node 20+, WebView2 (есть в Windows 11 из коробки).

```bash
npm install
```

Отладочный запуск:

```bash
npm run tauri dev
```

Релизная сборка и установщик:

```bash
npm run tauri build
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`.

## Для тестировщиков

### Установщик не подписан

Сертификат подписи кода для проекта не покупается, поэтому при запуске
установщика Windows покажет синий экран **«Система Windows защитила ваш
компьютер»**. Это ожидаемо и означает ровно одно: издатель неизвестен Microsoft.

Чтобы продолжить: **«Подробнее»** → **«Выполнить в любом случае»**.

Перед этим имеет смысл сверить контрольную сумму файла с опубликованной вместе
со сборкой:

```powershell
Get-FileHash .\ZeroNote_0.1.0_x64-setup.exe -Algorithm SHA256
```

### Куда приложение кладёт данные

> Ниже описано принятое решение. На сегодня реализована только установка для
> текущего пользователя; работа с папкой `data\` появляется в задаче 2.

Приложение не засоряет систему: настройки, темы, сессия и черновики лежат рядом
с исполняемым файлом, в подпапке `data\`.

Установка идёт **только для текущего пользователя**, в
`%LOCALAPPDATA%\Programs\ZeroNote\`, и не требует прав администратора. Это не
косметика: в `Program Files` папка была бы недоступна на запись, и черновики
несохранённых файлов молча терялись бы.

Если папка приложения всё же окажется недоступной на запись — например, при
запуске с флешки с защитой от записи, — приложение перейдёт на
`%LOCALAPPDATA%\ZeroNote\` и сообщит об этом в строке состояния.

Деинсталлятор пользовательские данные не трогает.

### Как сообщать о проблемах

К отчёту полезно приложить: версию Windows, версию ZeroNote, что делали, что
ожидали, что получили. Для проблем с открытием файла — его кодировку и тип
переносов строк из строки состояния.
