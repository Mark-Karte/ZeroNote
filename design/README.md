# Дизайн-референс

Прототип оформления, по которому делается этап 3. Сделан владельцем проекта
в паре с Claude Designer; лежит здесь, чтобы решение можно было проследить
и оспорить, как и всякое другое.

- `slate-reference.html` — прототип целиком: все экраны, темы, поведение.
  Открывается в браузере; рантайм прототипа (`support.js`) не нужен для чтения
  разметки и стилей.
- `slate-reference.md` — разбор: экраны, токены, размеры, поведение.

**Это референс, а не образец для переноса.** Где он расходится с моделью
ZeroNote, побеждает модель — решение Р-074. Что именно не берём и почему —
`DESIGN.md`, раздел 14.
