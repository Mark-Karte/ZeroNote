# Handoff: Slate — редактор файлов и связанных заметок

## Overview
Slate — десктопное приложение-редактор (Win/Linux), объединяющее три модели работы:
вкладки и мгновенное редактирование любых файлов (Notepad++), граф связей и `[[wiki-ссылки]]` (Obsidian),
дерево файлов + палитра команд + панели (VSCode). Прототип содержит одно окно и 5 экранов
внутри него, переключаемых вкладками, боковой полосой иконок и палитрой команд.

## About the Design Files
Файлы в этом бандле — **дизайн-референс, сделанный в HTML**: прототип, показывающий задуманный
внешний вид и поведение, а не продакшн-код для копирования. Задача — **воссоздать эти экраны
в существующем окружении целевого проекта** (React, Vue, Electron + React, Tauri, SwiftUI, native)
по его сложившимся паттернам и библиотекам. Если окружения ещё нет — выбрать подходящий стек
и реализовать дизайн в нём. Логика прототипа (класс `Component`) описывает состояния,
а не архитектуру приложения.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, интерактив и копирайт на русском.
UI следует воссоздавать точно, используя компоненты и токены целевой кодовой базы.

## Interactions & Behavior
- **Открытие экрана** добавляет вкладку, если её нет, и делает активной.
- **Закрытие вкладки** (крестик, `stopPropagation`): если закрыта активная — активной становится
  последняя оставшаяся; если вкладок нет — стартовый экран.
- **Палитра команд**: Ctrl/Cmd+K и Ctrl/Cmd+P открывают; ↑/↓ двигают выбор по кругу;
  Enter запускает; Esc закрывает; клик по подложке закрывает, клик по диалогу — нет.
- **Команды**: Перейти к файлу (код), Открыть граф, Поиск по всем файлам (переключает боковую
  панель на поиск), Новая заметка (заметка), Следующая тема, Настройки, Закрыть все вкладки.
- **Меню тем**: клик по кнопке в шапке открывает/закрывает; выбор темы закрывает меню;
  клик вне закрывает; Esc закрывает. Ctrl+Shift+T и клик по названию темы в строке состояния
  переключают тему по кругу.
- **Hover-состояния**: строка поиска — рамка `--ac`; строки списков — фон `--bg1`/`--bg3`;
  крестик вкладки — фон `--bg3`; иконки — цвет `--ac`.
- **Анимации**: `slateBlink` (курсор, 1.1s steps(1) infinite), `slateRise`
  (появление диалога и меню, .12-.14s ease-out), `slateFade` (подложка, .12s ease-out),
  transition .15s на переключателях настроек.
- **Прокрутка**: код — по обеим осям, дерево/поиск/превью/настройки — по вертикали;
  окно само не скроллится (`overflow: hidden` на body).

## State Management
- `theme` — id темы (`null` = взять из props).
- `view` — активный экран: `code | note | graph | settings | welcome`.
- `rail` — активная боковая панель: `files | search`.
- `tabs` — массив id открытых экранов, порядок = порядок вкладок.
- `palette` (bool) и `pi` (индекс выбранной команды).
- `themeMenu` (bool) — открыто меню тем.
- `settings` — массив из 5 булевых значений переключателей.
- Данных с сервера нет: дерево файлов, результаты поиска, граф, обратные ссылки и «недавнее» —
  статические массивы в логике прототипа. В реальном приложении это точки подключения
  файловой системы, индексатора и графа.

### Акцент
- Базовый `--ac`: **#7B8CFF**; альтернативы: #4FB286, #E8873A, #C74B78.
