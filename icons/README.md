# Знак ZeroNote

Исходный набор, нарисованный владельцем. Это **источник**, а не то, что берёт
сборка: Tauri читает `src-tauri/icons/`, и файлы туда кладутся задачей 25.

Знак — ноль с чертой: «zero» и штрих пера разом. Читается на 16 px, что и было
целью: в панели задач и на вкладке проводника он живёт именно в этом размере.

## Что здесь лежит

| Папка | Что | Для чего |
|---|---|---|
| корень | `zeronote-dark-*`, `zeronote-light-*` | основной знак, тёмный и светлый вариант, 16…1024 px плюс SVG |
| `macos/` | `zeronote-macos-*` | та же форма в пропорциях macOS (поле вокруг знака) |
| `tray/` | `zeronote-tray-black`, `zeronote-tray-white` | одноцветный силуэт для области уведомлений |

Тёмный вариант — знак на тёмной подложке, светлый — на светлой. Ни один из них
не прозрачный: подложка скруглённая и входит в рисунок.

## Что из этого используется

**Сейчас — ничего.** Приложение до задачи 25 показывает заглушку, собранную
скриптом `assets/make-placeholder-icon.ps1`.

По решению Р-097: в систему уходит **тёмный** вариант — он читается и на светлой,
и на тёмной панели задач. Знак внутри окна (шапка, стартовый экран) следует теме
приложения, потому что там фон наш.

`macos/` и `tray/` в первом круге не нужны: Linux и macOS вне области,
значка в области уведомлений у нас нет. Лежат как часть набора — выбрасывать
исходники, нарисованные под будущее, незачем.

## Чего не хватает для сборки

Windows нужен многоразмерный `.ico` (16, 32, 48, 64, 128, 256 в одном файле).
В наборе его нет — есть отдельные PNG. Собрать `.ico` из них и положить
в `src-tauri/icons/` — работа задачи 25.

## Происхождение

Файлы содержат метаданные C2PA — подпись инструмента, которым их рисовали.
На отображение они не влияют; при пересборке `.ico` не переносятся.
